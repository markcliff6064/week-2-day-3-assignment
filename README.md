# Week 2 Day 3 Assignment

## JavaScript DOM Manipulation

This project contains three interactive browser applications built using HTML, CSS, and JavaScript.

## Projects

### 1. Character Counter
![output Show on computer](https://github.com/markcliff6064/week-2-day-3-assignment/blob/95ac87b23759639821d28551a3a91e8767526855/Screenshot1.jpg)
A textarea that counts characters in real time.

Features:

* 280-character limit
* Live character counter
* Orange warning when close to the limit
* Red styling when the limit is exceeded
* Dynamic textarea border colour

### 2. Dynamic Shopping List
![output Show on computer](https://github.com/markcliff6064/week-2-day-3-assignment/blob/95ac87b23759639821d28551a3a91e8767526855/Screenshot2.jpg)
An interactive shopping list where users can manage their shopping items.

Features:

* Add items
* Set quantity
* Mark items as bought
* Delete items
* Display remaining items
* Empty-input validation
* Dynamic DOM element creation using `createElement()`

### 3. Calculator
![output Show on computer](https://github.com/markcliff6064/week-2-day-3-assignment/blob/95ac87b23759639821d28551a3a91e8767526855/screenshot3.jpg)
A simple functional calculator.

Features:

* Numbers 0–9
* Addition
* Subtraction
* Multiplication
* Division
* Decimal numbers
* Chained calculations
* Clear button
* Keyboard support

## JavaScript Concepts Practiced

* `querySelector()`

* Calculator state management
